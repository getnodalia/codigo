# Security policy

Please report a vulnerability in Código privately through
[GitHub private vulnerability reporting](https://github.com/getnodalia/codigo/security/advisories/new),
not in a public issue or pull request. Say which version you ran, on which platform, and how to
reproduce the problem.

Nodalia maintains Código and handles every report. Only the latest release receives security
fixes. Nothing has been released yet; until the first release, fixes land on `main`.

Código opens files and folders from untrusted places. A malformed file must produce an error, never
a crash or code execution; a report of either is welcome.
