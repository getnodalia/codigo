## Español

### Novedades

- **Asistentes de IA.** El panel *Asistente* (`Ctrl+Alt+I`) conversa sobre el archivo abierto o
  tu selección; *Explicar*, *Corregir*, *Refactorizar*, *Documentar* y *Escribir pruebas para este
  código* están en el menú Asistente. Cuando la respuesta es un cambio, *Aplicar* lo pone en el
  editor y se puede deshacer. Elige Anthropic, OpenAI, Ollama o cualquier dirección compatible con
  OpenAI en *Ajustes del asistente…*. Código no incluye ninguna clave ni cuenta: la clave se guarda
  solo en el llavero del sistema, se envía únicamente al servidor del proveedor (por https, o a tu
  propio equipo) y no aparece en ningún mensaje de error. Nada se envía hasta que lo pides.
- **Stash.** *Guardar los cambios en el stash* y *Aplicar el último stash y quitarlo*, en el menú
  Git y en la paleta.
- **Merge y resolución de conflictos.** *Fusionar una rama en esta…* y *Abortar la fusión*. Si
  quedan conflictos, una ventana muestra cada bloque del archivo y conserva el *actual*, el
  *entrante* o *ambos*, bloque a bloque; al terminar, *Marcar como resuelto* lo prepara.
- **Preparar por fragmentos.** En el diff de un archivo, un botón por fragmento prepara o
  despreparar solo esa parte.
- **Blame.** *Mostrar quién cambió cada línea* (`Ctrl+Alt+B`) escribe el autor, la fecha y el
  asunto del último cambio al final de la línea del cursor.
- **Crear un pull request desde Código.** Sube la rama actual y abre el pull request desde ella.
- **Comentarios en líneas de un diff.** En un pull request, pulsar el número de una línea abre un
  comentario sobre ella; las líneas con comentarios llevan un punto, con su hilo y una caja para
  responder.
- **Instalador para Windows (MSI).** Se instala solo para ti, sin permisos de administrador, en
  `%LOCALAPPDATA%\Programs\Nodalia\Codigo`, con acceso directo en el menú Inicio; instalar uno más
  nuevo actualiza en el sitio. El zip portátil sigue ahí. `codigo.exe` ahora lleva su icono.

### Notas

- Probado en la aplicación real: resolución de conflictos, merge, preparar por fragmentos, stash,
  blame y el asistente de punta a punta contra un servidor local compatible con OpenAI (incluido
  *Aplicar*).
- **No probado**: crear pull requests y comentarios en líneas contra un repositorio real de
  GitHub, el guardado de la clave en el llavero, y los servicios reales de Anthropic y OpenAI. El
  instalador MSI lo prueba la integración continua de Windows (instalar, actualizar, arrancar
  y desinstalar), no se ha abierto a mano en un Windows.
- Aún no hay completado de código en línea de la IA, edición de varios archivos por la IA ni un
  editor de merge a tres paneles.

## English

### What's new

- **AI assistants.** The *Assistant* panel (`Ctrl+Alt+I`) chats about the open file or your
  selection; *Explain*, *Fix*, *Refactor*, *Document* and *Write tests for this code* are in the
  Assistant menu. When the answer is a change, *Apply* puts it in the editor and it can be
  undone. Pick Anthropic, OpenAI, Ollama or any OpenAI-compatible address in *Assistant
  settings…*. Código ships no key and no account: the key is kept only in the system's keyring,
  is sent only to the provider's own host (over https, or to your own computer) and never
  appears in an error message. Nothing is sent until you ask.
- **Stash.** *Stash the changes* and *Apply the latest stash and remove it*, in the Git menu and
  the palette.
- **Merge and conflict resolution.** *Merge a branch into this one…* and *Abort the merge*. When
  conflicts are left, a window lists each block of the file and keeps *current*, *incoming* or
  *both*, one block at a time; when done, *Mark as resolved* stages it.
- **Staging by hunk.** In a file's diff, a button per hunk stages, unstages or discards just that part.
- **Blame.** *Show who changed each line* (`Ctrl+Alt+B`) writes the author, date and subject of
  the last change at the end of the cursor's line.
- **Create a pull request from Código.** It pushes the current branch and opens the pull request
  from it.
- **Comments on diff lines.** In a pull request, clicking a line's number opens a comment on it;
  lines with comments carry a dot, with their thread and a box to reply.
- **A Windows installer (MSI).** It installs for you only, with no administrator rights, into
  `%LOCALAPPDATA%\Programs\Nodalia\Codigo`, with a Start menu shortcut; installing a newer one
  upgrades in place. The portable zip is still there. `codigo.exe` now carries its icon.

### Notes

- Tried in the real app: conflict resolution, merge, staging by hunk, stash, blame, and the
  assistant end to end against a local OpenAI-compatible server (including *Apply*).
- **Not tried**: creating pull requests and line comments against a real GitHub repository,
  saving the key to the keyring, and the real Anthropic and OpenAI services. The MSI is tested
  by the Windows CI (install, upgrade, start and uninstall), not opened by hand on Windows.
- Not yet: inline AI completions, AI edits across several files and a three-pane merge editor.
