## Español

### Qué incluye

- **Un editor hecho para la velocidad**: solo se dibujan las filas que se ven, así que un archivo
  de un millón de líneas (45 MB) se abre y se desplaza sin problemas. Varios cursores y
  selecciones, ajuste de línea, buscar y reemplazar con recuento, operaciones de línea, deshacer
  ilimitado y Unicode bien tratado, con la codificación y los saltos de línea del archivo
  conservados al guardar.
- **Resaltado de sintaxis de 15 lenguajes** con tree-sitter: Rust, Python, JavaScript,
  TypeScript, JSON, TOML, Markdown, Bash, C, C++, Go, Java, HTML, CSS y YAML.
- **Servidores de lenguaje (LSP)**: errores subrayados mientras escribes, mensaje bajo el puntero,
  contadores en la barra de estado, información al pasar el cursor, autocompletado e ir a la
  definición. Código nunca instala un servidor por ti.
- **Terminal y consola de ejecución**: un terminal real bajo el editor, con pestañas, y `F5` para
  ejecutar el proyecto según lo que contiene la carpeta (`cargo run`, `npm start`, `go run .`…),
  además de Compilar, Probar y Comprobar. Las rutas `archivo:línea:columna` de la salida son
  enlaces.
- **Calidad y seguridad integradas**, sin servidor y sin que nada salga de tu ordenador: secretos
  escritos en el código, patrones inseguros, atajos de Rust que pueden provocar un pánico,
  funciones demasiado largas o complejas y bloques copiados, con una puerta de calidad y un clic
  para abrir el sitio exacto.
- **Herramientas para crear apps Nodalia**: «Nueva app Nodalia» genera una app Rust con el diseño
  de Nodalia, su ventana Acerca de, español e inglés con la prueba que comprueba cada texto, los
  lints y la CI de las demás apps. En proyectos Nodalia, el análisis de calidad revisa además sus
  reglas: colores escritos en el código, textos sin traducir y cabeceras de licencia.
- **Un icono propio para cada tipo de archivo** en el explorador y en las pestañas.
- **Proyectos**: explorador que respeta `.gitignore` con el estado de git en color, apertura
  rápida (`Ctrl+P`), búsqueda en todo el proyecto (`Ctrl+Mayús+F`) y paleta de comandos
  (`Ctrl+Mayús+P`).
- **Diseño Nodalia**: temas claro, oscuro y de alto contraste, controles de ventana redondos en
  Linux (los del sistema en macOS y Windows), menú global por D-Bus en Linux, la opción de reducir
  el movimiento y comprobación de actualizaciones dentro de la app. Español e inglés.

### Notas

- Para ver errores del código hace falta tener instalado el servidor de lenguaje que corresponda
  (rust-analyzer, pyright, gopls, clangd…).
- Aún no hay referencias, renombrado ni formato con LSP, correcciones desde el editor, avisos de
  dependencias vulnerables, git dentro del editor, depurador ni asistentes de IA.
- La app de macOS no está firmada con un Developer ID: la primera vez, ábrela con clic derecho >
  Abrir. En Windows, SmartScreen avisa la primera vez («Más información» > «Ejecutar de todas
  formas»).

## English

### What's in it

- **An editor built for speed**: only the rows on screen are laid out, so a million-line (45 MB)
  file opens and scrolls without trouble. Multiple cursors and selections, word wrap, find and
  replace with a match count, line operations, unlimited undo and Unicode that behaves, with the
  file's encoding and line endings kept when you save.
- **Syntax highlighting for 15 languages** through tree-sitter: Rust, Python, JavaScript,
  TypeScript, JSON, TOML, Markdown, Bash, C, C++, Go, Java, HTML, CSS and YAML.
- **Language servers (LSP)**: errors underlined as you type, the message under the pointer,
  counts in the status bar, hover, completion and go to definition. Código never installs a
  server for you.
- **A terminal and a run console**: a real terminal under the editor, with tabs, and `F5` to run
  the project according to what the folder contains (`cargo run`, `npm start`, `go run .`…),
  plus Build, Test and Check. A `path:line:column` in the output is a link.
- **Code quality and security, built in**, with no server and nothing leaving your computer:
  secrets written in the code, unsafe patterns, Rust shortcuts that can panic, functions that
  are too long or too complex, and copied blocks, with a quality gate and a click to open the
  exact place.
- **Tools for building Nodalia apps**: *New Nodalia app* creates a Rust app in the Nodalia Design
  Language with its About window, Spanish and English with the test that checks every string, the
  lints and the CI the other apps use. In Nodalia projects the quality analysis also checks their
  rules: colours written in the code, untranslated text and licence headers.
- **A symbol of its own for every file type** in the explorer and in the tabs.
- **Projects**: an explorer that respects `.gitignore` with git status in colour, quick open
  (`Ctrl+P`), search across the project (`Ctrl+Shift+F`) and a command palette (`Ctrl+Shift+P`).
- **Nodalia Design**: light, dark and high-contrast themes, round window controls on Linux (the
  system's own on macOS and Windows), a global menu over D-Bus on Linux, a reduced-motion option
  and an in-app update check. Spanish and English.

### Notes

- To see errors in your code, install the language server for it (rust-analyzer, pyright, gopls,
  clangd…).
- Not yet: references, rename and formatting through LSP, fixes from the editor, vulnerable
  dependency warnings, git in the editor, a debugger or AI assistants.
- The macOS app is not signed with a Developer ID: the first time, open it with right-click >
  Open. On Windows, SmartScreen warns the first time ("More info" > "Run anyway").
