*The debugger: a Debug button, breakpoints in the margin, stepping, the call stack, variables and expression evaluation.*

## Español

### Novedades

- **Depurador.** El botón del bicho junto a Ejecutar (o `F6`) compila el proyecto y lo ejecuta
  bajo un depurador. Un clic en el margen de los números de línea (o `F9`) pone o quita un punto
  de interrupción. Al parar, la línea se resalta en el editor y el panel Depurar muestra la pila
  de llamadas, las variables locales (se abren con un clic), un campo para evaluar expresiones, los
  puntos de interrupción y la salida del programa. La barra superior pasa a mostrar Continuar
  (`F8`), Paso por encima (`F10`), Paso al interior (`F11`), Paso hacia fuera (`Mayús+F11`) y
  Detener (`Mayús+F6`); todo está también en el menú Ejecutar.
- Funciona con proyectos de Rust (también C y C++) usando `lldb-dap` o GDB 14 o posterior, con Go
  mediante `dlv` y con Python mediante `debugpy`. Código no instala nada: si falta el depurador,
  dice cuál instalar.

### Notas

- Probado con `lldb-dap` y GDB sobre programas reales; los adaptadores de Go y Python aún no se
  han probado en una sesión real. Los puntos de interrupción no siguen las líneas si editas el
  archivo mientras no se depura, y no hay todavía puntos condicionales ni expresiones vigiladas
  que se conserven.
- Aún no hay referencias, renombrado ni formato con LSP, correcciones desde el editor, avisos de
  dependencias vulnerables, git dentro del editor ni asistentes de IA.

## English

### What's new

- **A debugger.** The bug button next to Run (or `F6`) builds the project and runs it under a
  debugger. A click in the line-number margin (or `F9`) sets or clears a breakpoint. When the
  program stops, the line is highlighted in the editor and the Debug panel shows the call stack,
  the local variables (a click opens them), a field to evaluate expressions, the breakpoints and
  the program's output. The top bar then shows Continue (`F8`), Step over (`F10`), Step into
  (`F11`), Step out (`Shift+F11`) and Stop (`Shift+F6`); all of it is in the Run menu too.
- It works with Rust projects (and C and C++) through `lldb-dap` or GDB 14 or newer, with Go
  through `dlv` and with Python through `debugpy`. Código installs nothing: when the debugger is
  missing it says which one to install.

### Notes

- Tested with `lldb-dap` and GDB on real programs; the Go and Python adapters have not been tried
  in a real session yet. Breakpoints do not follow their lines when you edit the file while not
  debugging, and there are no conditional breakpoints or watch expressions that persist yet.
- Not yet: references, rename and formatting through LSP, fixes from the editor, vulnerable
  dependency warnings, git in the editor or AI assistants.
