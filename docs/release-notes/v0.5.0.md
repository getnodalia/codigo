## Español

### Novedades

- **Referencias, renombrar y formato con LSP.** *Buscar referencias* (`Mayús+F12`) abre una lista
  de lugares donde se usa; *Renombrar símbolo* (`F2`) pide el nombre nuevo y aplica el cambio en todos
  los archivos que el servidor indique, y cada archivo se puede deshacer; *Dar formato
  al documento* (`Alt+Mayús+F`) usa el formateador del servidor. Si el archivo cambió mientras el
  servidor respondía, Código descarta la respuesta en lugar de aplicar una posición vieja.
- **Snippets con huecos que rellenar.** Escribe `fn`, `for`, `if`… y pulsa `Tab`: se abre el
  snippet, `Tab` y `Mayús+Tab` pasan de un hueco a otro y las copias de un mismo hueco cambian a la
  vez. Hay snippets para los lenguajes de Código y los tuyos se leen de `snippets.json` en la
  carpeta de configuración (*Editar snippets* lo abre; mismo formato que VS Code).
- **Minimapa.** Una imagen reducida de todo el archivo junto al editor, con la parte visible, las
  líneas cambiadas respecto a git y los problemas marcados. Pulsa o arrastra para desplazarte. Se
  quita en Preferencias o con *Mostrar minimapa*.
- **Editor dividido.** `Ctrl+\` divide el editor en dos paneles: lee un archivo mientras editas
  otro, o mira dos lugares del mismo archivo. Pulsar un panel le da el teclado; elegir una pestaña
  llena el panel en el que estás.
- **Diseño de la suite de Ingeniería.** Código pertenece a la suite de Ingeniería de Nodalia, y la
  ventana lo refleja: IBM Plex Sans para la interfaz e IBM Plex Mono para el editor y todos los
  valores, islas y cabeceras de panel de la suite y números de la barra de estado en monoespaciada.

### Notas

- Probado con rust-analyzer real: referencias, renombrado en varios archivos y formato, y los
  snippets, el minimapa y la división en la ventana. No se han probado con otros servidores de
  lenguaje.
- Aún no hay asistentes de IA, stash, blame, crear un pull request desde Código, preparación por
  fragmentos ni resolución de conflictos.

## English

### What's new

- **References, rename and format through LSP.** *Find references* (`Shift+F12`) opens a list
  of the places it is used; *Rename symbol* (`F2`) asks for the new name and applies the change in every
  file the server names, and each file can be undone; *Format document* (`Alt+Shift+F`) uses
  the server's formatter. If the file changed while the server was answering, Código drops the
  answer instead of applying a stale position.
- **Snippets with places to fill in.** Type `fn`, `for`, `if`… and press `Tab`: the snippet opens,
  `Tab` and `Shift+Tab` move between its places and copies of the same place change together.
  There are snippets for Código's languages, and yours are read from `snippets.json` in the
  configuration folder (*Edit snippets* opens it; same format as VS Code).
- **A minimap.** A scaled-down picture of the whole file beside the editor, with the part on
  screen, the lines changed against git and the problems marked. Click or drag to scroll. Turn it
  off in Preferences or with *Show minimap*.
- **A split editor.** `Ctrl+\` splits the editor into two panes: read one file while editing
  another, or look at two places of the same file. Clicking a pane gives it the keyboard; choosing
  a tab fills the pane you are in.
- **The Engineering suite design.** Código belongs to Nodalia's Engineering suite, and the window
  shows it: IBM Plex Sans for the interface and IBM Plex Mono for the editor and every value, the
  suite's islands and panel headers, and numbers in the status bar set in the mono face.

### Notes

- Tried against a real rust-analyzer: references, rename across several files and formatting, and
  snippets, the minimap and the split in the window. They have not been tried with other language
  servers.
- Not yet: AI assistants, stash, blame, creating a pull request from Código, staging by hunk and
  merge conflict resolution.
