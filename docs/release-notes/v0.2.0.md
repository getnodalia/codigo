## Español

### Novedades

- **Barra de acciones** junto a la paleta: Ejecutar, Parar y Terminal, siempre a mano. Los paneles
  de la barra lateral (archivos, búsqueda, calidad, problemas) cambian con iconos.
- **Panel de Problemas** (`Ctrl+Mayús+M`, el menú Ver o un clic en los contadores de la barra de
  estado): los errores y avisos de todos los archivos que ha revisado un servidor de lenguaje,
  los errores primero, y un clic abre el sitio.

### Correcciones

- **Las carpetas grandes ya no bloquean la ventana.** El árbol de archivos se lee en segundo plano
  y se va rellenando, ya no se redibuja entero en cada fotograma, y la apertura rápida, la
  búsqueda y el análisis de calidad no entran en `node_modules`, en `target` junto a un
  `Cargo.toml` ni en otras carpetas generadas, aunque no haya `.gitignore`. Al abrir otra carpeta
  se cancela la lista de archivos de la anterior.
- El estado de git de una carpeta con solo archivos nuevos ya no enumera cada archivo.

### Notas

- Aún no hay referencias, renombrado ni formato con LSP, correcciones desde el editor, avisos de
  dependencias vulnerables, git dentro del editor, depurador ni asistentes de IA.

## English

### What's new

- **An action bar** beside the palette: Run, Stop and Terminal, always at hand. The sidebar panels
  (files, search, quality, problems) switch with icons.
- **A Problems panel** (`Ctrl+Shift+M`, the View menu, or a click on the status bar counts): the
  errors and warnings of every file a language server has looked at, errors first, and a click
  opens the place.

### Fixes

- **Big folders no longer freeze the window.** The file tree is read in the background and fills
  in as it goes, it is no longer redrawn whole on every frame, and quick open, search and the
  quality analysis stay out of `node_modules`, `target` beside a `Cargo.toml` and other generated
  folders, even with no `.gitignore`. Opening another folder cancels the previous folder's file
  list.
- Git status of a folder with only new files no longer lists each file.

### Notes

- Not yet: references, rename and formatting through LSP, fixes from the editor, vulnerable
  dependency warnings, git in the editor, a debugger or AI assistants.
