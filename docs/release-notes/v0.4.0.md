## Español

### Novedades

- **Los archivos se abren al instante.** Pulsar un archivo del árbol ya no espera a nada: los
  archivos grandes se leen y se analizan fuera de la ventana, el texto aparece primero y los
  colores llegan un instante después, y en las líneas larguísimas solo se maqueta lo que se ve.
- **Ejecutar y Depurar siempre.** Código reconoce más proyectos (Gradle, Maven, CMake, Make,
  Deno, Zig, Swift, Elixir, Flutter, Ruby, PHP y los de antes), también a partir del archivo que
  tienes abierto. Si no reconoce nada, te pregunta una vez cómo ejecutarlo o qué depurar y lo
  recuerda en la carpeta `.codigo` del proyecto. Un archivo suelto también se puede depurar.
- **Git en la ventana.** El panel Control de versiones (`Ctrl+Shift+G`) muestra los cambios, abre la
  diferencia de cada archivo, prepara y quita de preparados, descarta (con un segundo clic para
  confirmar), confirma (`Ctrl+Intro` en el mensaje), cambia y crea ramas, y obtiene, trae y sube.
  Usa el programa `git` de tu equipo, así que tus claves SSH y tu gestor de credenciales siguen
  funcionando.
- **GitHub en la ventana.** El panel GitHub (`Ctrl+Shift+H`) lista los pull requests e incidencias
  abiertos del repositorio en el que estás, los pull requests que abriste o que esperan tu
  revisión, y tus repositorios. Un pull request se abre en su propia ventana con la descripción,
  las comprobaciones, los archivos con sus diferencias y la conversación; puedes comentar,
  aprobar, pedir cambios o traer su rama. *Clonar repositorio…* (en la página de inicio y en el
  menú GitHub) acepta una dirección o `propietario/nombre` y abre el clon.
- **Sesión de GitHub sin coste ni cuentas nuevas.** Inicia sesión con la sesión de la CLI de
  GitHub o con un token personal; el token se guarda en el llavero del sistema y en ningún otro
  sitio. El inicio de sesión desde el navegador está incluido pero necesita una app OAuth de
  GitHub: solo aparece si se define `CODIGO_GITHUB_CLIENT_ID`. Código no incluye el cliente de nadie.

### Notas

- Probado con repositorios reales: estado, diferencias, preparar, confirmar y clonar, y lecturas
  de datos públicos de la API de GitHub. Las revisiones (aprobar, pedir cambios, comentar), el
  guardado en el llavero y el inicio de sesión desde el navegador no se han probado todavía con
  una cuenta real.
- Aún no hay preparación por fragmentos, resolución de conflictos, stash, comentarios en una línea
  de la diferencia ni crear un pull request desde Código. Tampoco referencias, renombrado ni
  formato con LSP, ni asistentes de IA.

## English

### What's new

- **Files open at once.** Clicking a file in the tree no longer waits for anything: big files are
  read and parsed off the window, the text shows first and the colours arrive a moment later, and
  very long lines lay out only what is on screen.
- **Run and Debug, always.** Código recognises more projects (Gradle, Maven, CMake, Make, Deno,
  Zig, Swift, Elixir, Flutter, Ruby, PHP and the earlier ones), also from the file you have open.
  When it recognises nothing it asks once how to run it or what to debug, and remembers the answer
  in the project's `.codigo` folder. A lone file can be debugged too.
- **Git in the window.** The Source control panel (`Ctrl+Shift+G`) shows the changes, opens each
  file's diff, stages and unstages, discards (a second click confirms), commits (`Ctrl+Enter` in
  the message box), switches and creates branches, and fetches, pulls and pushes. It runs the
  `git` program on your computer, so your SSH keys and credential helper keep working.
- **GitHub in the window.** The GitHub panel (`Ctrl+Shift+H`) lists the open pull requests and
  issues of the repository you are in, the pull requests you opened or that wait for your review,
  and your repositories. A pull request opens in a window of its own with its description, checks,
  files with their diffs and conversation; you can comment, approve, request changes or check its
  branch out. *Clone repository…* (on the welcome page and in the GitHub menu) takes an address or
  `owner/name` and opens the clone.
- **Signing in costs nothing and needs no new account.** Use the GitHub CLI session or a personal
  access token; the token is kept in the system's keyring and nowhere else. Signing in from the
  browser is built in but needs a GitHub OAuth app, so it only shows when
  `CODIGO_GITHUB_CLIENT_ID` is set. Código ships no one else's client.

### Notes

- Tried against real repositories: status, diffs, staging, committing and cloning, and reads of
  public data from GitHub's API. Reviews (approve, request changes, comment), saving to the
  keyring and the browser sign-in have not been tried with a real account yet.
- Not yet: staging by hunk, merge conflict resolution, stash, comments on a diff line or creating
  a pull request from Código. Also not yet: references, rename and formatting through LSP, and AI
  assistants.
