Novedades: Código se puede personalizar a fondo. Preferencias es ahora una ventana grande con categorías y un buscador que recorre todos los ajustes; hay trece temas de color además del de Nodalia, cada color del editor y del código se puede cambiar, y se elige la fuente del código entre todas las instaladas.

*What's new: Código can be customised in depth. Preferences is now a large window with categories and a search through every setting; there are thirteen colour themes besides the Nodalia one, every colour of the editor and of the code can be changed, and the code font is picked from everything installed.*

## Español

### Novedades

- **Preferencias grandes.** Siete categorías (Apariencia, Tema de colores, Editor, Archivos y
  guardado, Terminal, Herramientas y asistente, Avanzado) y un buscador que encuentra cualquier
  ajuste por su nombre o su descripción. Cada cambio se aplica y se guarda al momento.
- **Temas de color.** Nodalia (sigue los colores de la ventana), Dracula, One Dark, Monokai,
  Solarized oscuro y claro, GitHub claro y oscuro, Nord, Gruvbox oscuro y claro, Tokyo Night y
  Catppuccin Mocha y Latte. Una vista previa con código muestra el resultado al elegir.
- **Cada color, a tu gusto.** Cambia el fondo, el texto, los números de línea, la selección, el
  cursor, la línea actual y el color de cada tipo de código (palabras clave, cadenas, comentarios,
  funciones, tipos…); *Restablecer* devuelve cada uno al del tema.
- **Fuente del código.** Elige cualquier fuente instalada en el equipo (las de ancho fijo primero,
  con buscador), su tamaño y la altura de línea.
- **Cursor y guías.** Cursor de línea, bloque o subrayado, con o sin parpadeo; reglas en las
  columnas que quieras (por ejemplo 80 y 100) y guías de sangría.
- **Zoom de la interfaz** del 75 % al 200 %, y **programa del terminal** a elegir (una ruta o un
  nombre como `fish` o `zsh`; vacío usa tu shell de inicio de sesión).
- **Restablecer todas las preferencias**, conservando tus proyectos recientes.

### Notas

- **Probado en la aplicación real** (Linux, X11): se abrieron las Preferencias, se cambió de
  categoría, se eligió un tema, se eligió una fuente (queda guardada en `settings.json`) y se usó el
  buscador. Pruebas automáticas cubren la lectura y el saneado de los ajustes, los temas, los
  colores y la selección del shell.
- **No probado**: macOS y Windows reales; el selector de fuentes se ha comprobado solo con las
  fuentes de Linux.
- **Todavía no**: importar un tema de VS Code, ajustes por lenguaje y un editor de atajos. La
  conexión nativa con GitHub y GitLab llegará en la próxima versión.

## English

### What's new

- **A large Preferences window.** Seven categories (Appearance, Colour theme, Editor, Files and
  saving, Terminal, Tools and assistant, Advanced) and a search that finds any setting by its name
  or its description. Every change is applied and saved at once.
- **Colour themes.** Nodalia (follows the window's colours), Dracula, One Dark, Monokai, Solarized
  Dark and Light, GitHub Light and Dark, Nord, Gruvbox Dark and Light, Tokyo Night and Catppuccin
  Mocha and Latte. A code preview shows the result as you pick.
- **Every colour, your way.** Change the background, text, line numbers, selection, cursor, current
  line and the colour of each kind of code (keywords, strings, comments, functions, types…);
  *Reset* takes each back to the theme's.
- **Code font.** Pick any font installed on the computer (fixed-width ones first, with a search),
  its size and the line height.
- **Cursor and guides.** A line, block or underline cursor, blinking or not; rulers at any columns
  you like (say 80 and 100) and indent guides.
- **Interface zoom** from 75 % to 200 %, and a choice of **terminal program** (a path or a name such
  as `fish` or `zsh`; empty uses your login shell).
- **Reset all preferences**, keeping your recent projects.

### Notes

- **Tried in the real app** (Linux, X11): Preferences opened, a category was switched, a theme was
  picked, a font was picked (it is saved in `settings.json`) and the search was used. Automatic
  tests cover reading and sanitising the settings, the themes, the colours and the shell choice.
- **Not tried**: real macOS and Windows; the font picker was only checked against Linux fonts.
- **Not yet**: importing a VS Code theme, per-language settings and a keybindings editor. Native
  GitHub and GitLab integration comes in the next version.
